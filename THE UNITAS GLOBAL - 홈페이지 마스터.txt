1. [Claude Code] (딥 아키텍처 및 코어 멀티 파일 빌드)
1-1 용도: Three.js 기반 웜홀 셰이더, Web Audio API 실시간 사운드 엔진, 코인-코어 차감 라우팅의 전면적 코드 통합.

1-2 명령어:

Bash
claude "Initialize THE UNITAS GLOBAL 홈페이지 마스터 Rev 1 architecture. Implement a zero-buffer WebGL quantum wormhole with GLSL gravitational lensing, a real-time Web Audio API generative ambient/synth soundscape engine with hover frequency shifts, a frosted glass neural lock UI, and a Supabase-backed Coin-Core balance deduction routing system for Arche, Arena, Score, Fate, Codex22."
1-3 설명 (시나리오):

제국의 뼈대를 구축하는 대격변의 서막입니다. 방문자가 메인 홈페이지에 진입하는 순간, 복잡한 외부 미디어 로딩으로 인한 지연(Lag)을 제로(0)로 수렴시킨 제로-버퍼 퀀텀 웜홀(Quantum Wormhole)이 가동됩니다. Three.js와 GLSL 셰이더 기술을 통해 블랙홀의 중력 렌즈 효과와 양자 입자들이 화면 전체를 휘감으며 웅장한 카운트다운을 시각화합니다.

이와 동시에 외부 오디오 파일을 일절 쓰지 않고 브라우저 내부에서 실시간으로 연주되는 Web Audio API 제너레이티브 사운드 엔진이 깨어납니다. 방문자가 아르케, 아레나, 스코어, 페이트, 코덱스22 등의 서브 모듈 위로 마우스를 올릴 때마다 주파수 대역이 실시간으로 요동치며 미래지향적 신디사이저 톤으로 변환됩니다. 또한, 화면 전체를 감싸는 차가운 투명 유리 장벽(프로스트 글래스 뉴럴 락)이 무분별한 이탈을 막고, 선언문 정독 후 [싱크로나이즈]를 타격해야만 선명한 제국의 인터페이스가 해제되는 초보안 몰입형 라우팅 구조를 완성합니다.

2. [Roo Code] (모듈식 컴포넌트 스캐폴딩)
2-1 용도: 로그인 모달, SMS/이메일 시큐어 인증 창, 코인 충전 지갑 UI, 5대 서브 페이지 컴포넌트의 모듈별 조립.

2-2 명령어:

Plaintext
@workspace /scaffold Implement modular components for 홈페이지 마스터 Rev 1: 1) Cinematic quantum wormhole gate with 3s gravitational countdown, 2) Frosted glass neural lock synchronization wall, 3) Secure Auth modal supporting SMS/Email OTP + Instant Signup, 4) Coin-Core live balance tracker and per-module token deduction interface.
2-3 설명 (시나리오):

Claude가 세워놓은 거대한 뼈대 위에, 사용자가 직접 상호작용하는 정교한 UI 컴포넌트들을 조립하는 단계입니다. 방문자가 서브 페이지를 클릭하는 순간 페이지가 통째로 깜빡이며 넘어가는 촌스러운 방식을 거부합니다. 대신, 화면 위로 매혹적인 홀로그램 인증 창이 스르륵 슬라이드 업 됩니다.

신규 접속자는 간결한 원클릭 가입으로 즉시 제국의 시민이 되며, 기존 가입자는 아이디·비밀번호 입력 후 휴대폰(SMS)이나 이메일로 날아온 6자리 시큐어 OTP 토큰을 입력하는 즉시 철통같은 보안 속에서 본인 인증을 마치고 접속합니다. 접속과 동시에 우측 상단의 코인-코어 지갑(Coin-Core Wallet) 실시간 잔고 트래커가 작동하여, 각 모듈을 이용할 때마다 0.1초 만에 토큰이 정밀하게 차감되는 자율 경제 생태계의 모듈 부품들이 맞물려 돌아가도록 조립합니다.

Plaintext
// Optimize Tailwind CSS backdrop-filter performance, Canvas particle rendering loop, and Web Audio AnalyserNode smoothing for Rev 1.
3-3 설명 (시나리오):

코드를 작성하고 실시간으로 시각적 쾌적함을 검증하는 단계입니다. 프로스트 글래스의 초미세 블러 효과(backdrop-filter: blur(16px))와 캔버스 입자 렌더링 루프는 화려하지만 모바일이나 저사양 PC에서는 렉(Lag)을 유발할 잠재적 단점이 있습니다.

이 미세한 리스크를 완벽하게 보완하기 위해, Gemini Code Assist가 추가 토큰 비용 없이 실시간으로 자바스크립트 프레임레이트를 60 FPS로 고정하고, Web Audio의 아날라이저 노드(AnalyserNode) 스무딩 알고리즘을 최적화합니다. 단 하나의 끊김도 허용하지 않는 매끄러운 '초신비 시네마틱 체험'의 마감재를 다듬는 과정입니다.
