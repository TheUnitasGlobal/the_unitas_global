🚀 [1단계: 통합 연동 환경 주입 명령어]
VS Code의 모든 도구와 단축키, 빌드 태스크를 하나로 묶기 위해 [Claude Code] 또는 [PowerShell]에 아래 명령어를 투입하여 통합 설정 파일(.vscode/tasks.json, .vscode/settings.json, .mcp/config.json)을 구축합니다.

⚡ 실행 대상: [Claude Code] (우측 Claude Code 입력창)
Plaintext
@workspace /scaffold Implement full 5-Domain Integration Configuration:
1) Update .vscode/tasks.json with one-click tasks:
   - "Dev: Root Static" -> npx http-server . -p 8080
   - "Dev: Web Next.js" -> cd web && npm run dev
   - "Build: Full Portal" -> cd web && npm run build
   - "Git: Sovereign Sync" -> git add . && git commit -m "feat: sovereign multi-domain sync" && git push origin main
2) Configure .vscode/settings.json to optimize co-existence of Claude Code, Roo Code, and Gemini Code Assist without shortcut conflicts.
3) Wire .mcp/config.json for Supabase (read-only safe) and Filesystem MCP servers.
🏛️ [2단계: 도구별 전용 역할 및 맞춤형 명령어 규격]
향후 모든 작업은 각 도구의 특성에 맞추어 아래와 같이 분담하여 명령을 하달하십시오.

1. 🧠 [Claude Code] (심층 설계 및 대규모 파일 리팩토링)
주요 장점: 프로젝트 전체 맥락 이해, 수십 개 파일의 일괄 수정, 아키텍처 재설계.

표준 명령어 양식:

Plaintext
[Claude Code]
@workspace /scaffold [아키텍처/기능명]:
1) [전체 시스템 구조 정의]
2) [다국어 i18n 및 백엔드 API 연결]
3) [빌드 무결성 검증 npm run build]
2. 🛠️ [Roo Code] (개별 UI 컴포넌트 및 정밀 스캐폴딩)
주요 장점: 단계별 세부 파일 생성, 미세 CSS/Tailwind 인터랙션 구현, 퀴즈/게임 모듈 조립.

표준 명령어 양식:

Plaintext
[Roo Code]
@workspace /scaffold Create modular interactive component for [모듈명]:
- Location: /web/components/[폴더명]
- Theme: Deep Space Black with Neon Glow
- Interaction: Framer Motion hover & click micro-SFX
3. ⚡ [Gemini Code Assist] (실시간 인라인 지능 지원)
주요 장점: 코드 작성 중 Tab 키를 통한 즉각적인 완성, 단일 함수 단위 최적화.

운용 방식: 에디터 내에서 주석(//)으로 원하는 로직을 적으면 즉시 코드를 인라인으로 제시합니다.

4. 🛡️ [GitHub] (영속성 보존 및 글로벌 버전 관리)
주요 장점: 코드 유실 방지, 원격 브랜치 동기화, 제국 자산 아카이빙.

표준 명령어 양식 (PowerShell 터미널 입력용):

PowerShell
# [GitHub] 제국 코드 영구 보존 동기화
git add .
git commit -m "feat: deploy latest sovereign platform update"
git push origin main
5. 💻 [PowerShell] (서버 구동 및 로컬 환경 관제)
주요 장점: 터미널 기반 빠른 런타임 제어, 포트 확인, 프로세스 백그라운드 구동.

표준 명령어 양식:

PowerShell
# [PowerShell] 차세대 Next.js 포털 구동
cd web
npm run dev
