The Unitas Global OÜ의 웹 프로젝트(web) 인프라 전반에 걸쳐, 창립자 황두영(Dooyeong Hwang)의 최상위 운영 헌법 및 사상(무자본 1인 AI 완전 자동화, 제로 타협 원칙, 페일클로즈드 무결성 검증)을 완벽히 이식하고, 아래의 셋팅과 최종 동기화 작업을 즉시 자율 실행해 다오.

1. 로우메모리 아머 및 온디맨드 인텔리전스 팩토리 활성화:
   - 유휴 백그라운드 파일 워처(node_modules, .next 등)의 메모리 낭비를 철저히 차단하여 런타임을 보호하되, 명령이 하달되는 즉시 VS Code 내부의 모든 고성능 툴, 에이전트 스킬, 시각·오디오·UI 컴포넌트 아키텍처를 100% 온디맨드로 초고속 호출하여 단 하나의 타협도 없는 최고 수준의 걸작을 자율 자동화로 완성한다.

2. 소버린 이념 및 목적 사상 영구 각인:
   - 본 플랫폼이 전 세계 디지털 노마드와 소상공인이 자율 에이전트 팩토리를 임대·구동할 수 있는 탈중앙화 소버린 SaaS 생태계로 확장될 수 있도록, 모든 코드 구조와 메타데이터가 완벽한 무결성과 확장성을 지니도록 설계·보완한다.

3. 페일클로즈드 게이트 무결성 검증 (Fail-Closed Gate):
   - Git 동기화 전 반드시 사전 예방적 무결성 검증(npm --prefix web run typecheck 및 npm --prefix web run build, 300초 타임아웃)을 강제 수행하여 에러 유입을 원천 차단한다.

4. 최종 Git 동기화 및 프로덕션 라이브 배포 자율 실행:
   - 검증 완료 후 변경된 모든 코드를 스테이징하고 커밋(git add 및 git commit)한다.
   - 원격 저장소(GitHub)로 푸시(git push origin main)를 실행한다.
   - Vercel 프로덕션 환경으로 최종 라이브 배포를 즉시 완료하여 전 세계에 완벽히 라이브로 반영한다.
