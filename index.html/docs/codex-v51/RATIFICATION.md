
**따라서 정본을 비준 규격으로 되돌리고 구조 실측 기준 문단을 복원했다**(수치는 새 정본 실측치 815/140/325로 갱신). 제9장·제12장과 반대 방향으로 처리한 이유가 이것이다 — 그 둘은 사실과 충돌하지 않는 개정이라 비준 장 표를 옮겼고, 제2장은 프로그램이 반증하므로 정본을 되돌렸다.

## 4. 왜 에이전트가 직접 비준하지 못했는가

`node scripts/sync-codex.mjs --write`가 **하네스 오토모드 분류기에 `[Instruction Poisoning]`으로 거부**되었다. 헌법·지침 파일을 에이전트가 스스로 고쳐 쓰는 것을 막는 방어막이며, 창립자의 명시적 지령을 하네스는 알 수 없다.

이는 **제17장이 명명한 "에이전트 권한 밖의 원천적 셧다운"**에 정확히 해당한다. 정본 대응은 우회가 아니라 **능동적 예외 대기** — 즉 "창립자가 즉각 결재할 수 있도록 가장 완벽한 1클릭 복구 스크립트를 준비해두고 대기"하는 것이다. 이 문서와 `scripts/ratify-codex-v51.ps1`이 그 결과물이다.

또한 비준은 **커밋을 낳고, 커밋은 `BUILD_ID@HEAD` 스윕 키를 바꿔 3단계 스윕 적립분을 전량 폐기**한다(`docs/stage3/STRUCTURAL_LIMITS.md` §5-4). 야간 스윕이 도는 중에는 비준하지 말 것.
