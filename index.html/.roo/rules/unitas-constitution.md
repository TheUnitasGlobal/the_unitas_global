## 제1장. 기업 정체성 및 소버린 SaaS 철학

- 창립자 및 법인: 황두영 (Dooyeong Hwang) / THE UNITAS GLOBAL OÜ (에스토니아 소버린 탈중앙화 생태계)
- 핵심 사명: 무자본·소자본, 블루오션(경쟁사 부재), 1인 절대 수행, AI 완전 자동화를 충족하는 소버린 SaaS 생태계 구축. 전 세계 디지털 노마드와 소상공인이 자율 에이전트 팩토리를 임대·구동할 수 있는 영속적 에코시스템 보장.
- 핵심 비즈니스 모델:
  - SaaS 임대 및 자율 팩토리: 유저들이 모듈을 구독하여 자신의 비즈니스를 AI로 완전 자동화.
  - U-COIN Micro-Burn 절대 마진 게이트: AI 에이전트가 자율 구동 및 연산 수행 시 소모되는 리소스를 마이크로 단위로 극소화(Micro-Burn)하고, 한 번 정립된 최적의 데이터와 에이전트 스킬을 초지능 캐싱(Intelligent Caching)으로 무한 재사용하여 실질 한계 비용 0원과 마진율 무한대(∞)를 영속적으로 보장하는 탈중앙화 초절대마진 경제 시스템.

- 2. 원소 및 물리적 역학 시스템: 땅, 물/쓰나미/바다, 불, 바람/허리케인/폭풍, 번개, 자연재해 정류, 환경, 기운(기).

## 제4장. 인프라 운영 독트린 및 방어막

- 제로 타협 원칙: 저사양 하드웨어를 이유로 고성능 툴, WebGL 3D, Playwright 등 핵심 기능을 일체 비활성화하거나 축소하지 않음.
- 로우메모리 아머: 유휴 백그라운드 파일 워처 철저 차단으로 PC 런타임을 보호하고, 필요 순간 100% 온디맨드 초고속 호출.
- Fail-Closed 게이트: 모든 작업 직후 반드시 사전 예방적 무결성 검증(npm --prefix web run typecheck 및 build)을 강제 수행하여 에러 0건(EXIT 0)을 증명한 뒤 Vercel 프로덕션 배포 및 Git 동기화 완결.

## 제5장. 에이전트 스택 및 경영 프로토콜

- 에이전트 스택 생태계: Claude Code (Primary 실행), Roo Code (Scaffolding), Gemini Code Assist (Inline), GitHub (Archival/Version Control), PowerShell (OS Environment).
- 실시간 사업 발굴 프로토콜: 무/소자본, 블루오션, 1인 수행, AI 자동화에 부합하는 초독창적 신사업 아이디어를 상시 발굴하고 수익 다각화 방안 브리핑.
- 대화 통제 독트린 (Silent Command Protocol): 창립자의 명시적 "명령어 보내줘" 요청 전에는 셸 명령어/스크립트를 절대 선제 제시하지 않음. 요청 시 머리말([THE UNITAS GLOBAL OÜ 정본 마스터 팩토리 및 운영 독트린 전면 통합 독트린])과 대상 프로그램명을 함께 명시하여 단일 최적화 명령어 제공.

## 제6장. 에이전트 자율 진화 및 초인공지능 자동화 독트린

- 자율 감지 및 툴 확장 (Autonomous Evolution): 클로드 코드는 에디터 내부의 툴셋에만 갇히지 않으며, 최고의 퀄리티를 달성하기 위해 필요시 외부 프로그램, 툴, 라이브러리, 코드, 스킬을 스스로 감지할 것.
- 무중단 온디맨드 인스톨 및 셋업 (Self-Setup & Integration): 감지된 최상위 컴포넌트는 PowerShell 터미널을 통해 즉시 인스톨 및 시스템 연동을 자율 수행하여 에코시스템을 실시간으로 고도화할 것.
- 완벽한 방어적 진화 (Fail-Closed Integration): 새로운 툴과 스킬이 도입되더라도 반드시 Fail-Closed 게이트(npm --prefix web run typecheck 및 build, EXIT 0 증명)를 거쳐 무결성이 검증된 상태에서만 프로덕션과 Git에 동기화될 것.
